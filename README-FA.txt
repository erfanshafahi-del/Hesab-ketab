پروژه اندروید «حساب کتاب» — ساخت APK خودکار
============================================

این پروژه اپلیکیشن وب حساب کتاب را داخل یک برنامه اندروید (WebView) قرار می‌دهد.

روش ساده‌تر ساخت APK بدون نصب Android Studio روی گوشی/کامپیوتر:
1) فایل ZIP را استخراج کنید.
2) یک مخزن جدید در GitHub بسازید (Repository). آن را Public یا Private انتخاب کنید.
3) فایل‌های داخل پوشه hesab-ketab-android-project را در مخزن آپلود کنید؛ پوشه مخفی .github هم باید آپلود شود.
4) در مخزن GitHub وارد تب Actions شوید.
5) اگر از شما خواست، گزینه Enable Actions را بزنید.
6) از فهرست سمت چپ گزینه Build Hesab Ketab APK را انتخاب کنید و روی Run workflow بزنید.
7) پس از اتمام موفق، همان اجرای Workflow را باز کنید.
8) پایین صفحه، در بخش Artifacts روی hesab-ketab-debug-apk بزنید تا APK دانلود شود.
9) ZIP دانلودشده را استخراج کنید؛ فایل app-debug.apk داخل آن است. آن را به گوشی منتقل و نصب کنید.

اگر Actions خطا داد، از صفحه اجرای ناموفق اسکرین‌شات بگیرید و ارسال کنید تا خطا را بررسی کنیم.

نکته‌ها:
- این پروژه خروجی debug APK می‌سازد؛ برای نصب شخصی مناسب است، اما نسخه انتشار فروشگاهی نیست.
- APK در این محیط کامپایل نشده؛ ساخت نهایی در GitHub Actions انجام می‌شود.
- پیش از جایگزینی نسخه قبلی برنامه، از داده‌های مهم پشتیبان بگیرید.
- هرگز کلیدها یا رمزهای شخصی خود را در مخزن قرار ندهید.
